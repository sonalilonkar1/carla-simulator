# CMPE 281 CARLA Simulator Labs

CARLA labs for CMPE 281 using the SJSU COE HPC cluster, SLURM, Apptainer, Python, and NVIDIA GPUs.

## Labs

- Lab 1: Vehicle control and RGB camera capture
- Lab 2A: Stopped-vehicle emergency braking
- Lab 2B: Pedestrian-crossing emergency braking
- Lab 2C: Traffic-signal compliance
- Lab 3: Collision detection and accident reporting
- Lab 4: AI route navigation with RGB and LiDAR

## Video demonstrations

[Open the CARLA demonstration videos](https://drive.google.com/drive/folders/1T1vytaZXpTSqYCbUHWaLb6Lk970z5pxr?usp=drive_link)

## HPC safety

Submit all CARLA and GPU workloads through SLURM. Never run CARLA directly on the HPC login/head node.

## Required environment

- CARLA 0.9.16
- Python 3.11
- Apptainer
- SLURM
- NVIDIA GPU
